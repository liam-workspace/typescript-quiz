Primary Practice as an installable mobile PWA

CLICKABLE PROTOTYPE

Student side of the quiz app, redesigned phone-first and wired for the things a PWA adds: install, offline use, safe saving, and update handling. Clock, saving and scoring are simulated in the browser.

Try this

  1. Sign in, then tap Install on the home screen banner.
  2. On Practice Test 3 tap Save offline, then switch the network to offline below.
  3. Start the test, play a recording, answer, and watch the save indicator queue answers.
  4. Go back online: the queue flushes. Then finish the reading section and hand in.
  5. Open the result, review answers, and check History and Profile.
  6. Use Simulate new version during a test: the update waits until you finish.
Left out on purpose
  • Admin console (stays desktop-first).
  • Real auth, audio, server timers and grading.
  • Language picker, Library empty state, paging.
  • Real service worker, manifest and web push.
